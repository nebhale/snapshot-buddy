Before you begin

Configure your printer and named go2rtc stream in the configuration file, then restart Snapshot Buddy. Check that the live camera is available in the app.

Using both Buddy apps?

Use the same relay destination for both apps. Samplicator copies metrics to each app. Keep both apps’ snippets, and point every M334 at the relay’s LAN address and port. Approve the metrics destination on your printer if prompted.

What happens next

A START marker opens a session. Each LAYER marker requests a snapshot. A STOP marker requests the final snapshot and closes the session.

If START is not received, the first LAYER marker opens a recovered session. Missing LAYER markers leave layers without snapshots. A STOP marker without an active session does not open one.

Start and end blocks each send three markers, 1.1 seconds apart: 2.2 seconds of waiting at each boundary. Layer change blocks send two markers, 100 ms apart. Copy updated blocks and re-slice for changes to take effect.

After a manual close, LAYER markers are ignored until a new START marker or application restart. A new START marker also closes an unfinished previous session. Active sessions survive application restarts; there is no inactivity timeout.

Long filenames or names containing characters other than ASCII letters, digits, spaces, underscores, periods, and hyphens use Print as a fallback to fit the printer’s metric limit. The session timestamp helps distinguish these prints.

Snapshots are requested after queued movement finishes. Capture failures remain visible in the session, and timelapses use only saved snapshots. Closing a session manually keeps its snapshots without requesting a final capture. No color-change snippet is needed.

Sessions, snapshots, and videos are kept until you delete the session. Download the original snapshots or create a timelapse from the session page. Deleting a session permanently removes its snapshots and videos.
