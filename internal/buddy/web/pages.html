What happens next

A START marker opens a print. Each layer marker saves a fresh image, and STOP saves the final image and closes the session. If START is lost, the first layer marker opens a recovered session.

After a manual close, loose layer markers are ignored until START or an application restart. A new START also closes an unfinished previous session.
